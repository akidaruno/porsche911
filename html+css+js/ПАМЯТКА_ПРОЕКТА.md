# 📋 ПАМЯТКА ПО ПРОЕКТУ - Porsche 911 Website

## 🎯 Общее описание проекта
Статический веб-сайт о Porsche 911, созданный на чистом HTML, CSS и JavaScript. Сайт включает современный дизайн, анимации, систему авторизации и адаптивную верстку.

---

## 📁 Структура файлов

### Основные файлы:
- **`index.html`** - главная страница сайта
- **`history.html`** - страница истории Porsche 911
- **`styles.css`** - все стили сайта
- **`app.js`** - JavaScript логика и интерактивность

### Медиафайлы:
- **`hero.jpg`** - главное изображение для hero-секции
- **`icon.png`** - иконка сайта (favicon)
- **`p1.jpg` - `p8.jpg`** - изображения для галереи и карточек

### 4. Intersection Observer (анимации при скролле)

```javascript
const io = new IntersectionObserver(entries => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('in');
      io.unobserve(entry.target);
    }
  });
}, { rootMargin: '0px 0px -10% 0px', threshold: 0.1 });

$$('.reveal').forEach(el => io.observe(el));
```

**Объяснение:**

- `IntersectionObserver` - API для отслеживания видимости элементов
- `isIntersecting` - элемент виден в области просмотра
- `rootMargin` - отступы от области просмотра
- `threshold` - процент видимости для срабатывания

### 5. Параллакс эффект

```javascript
const heroImg = $('#heroParallax');
let latestScrollY = 0;
let ticking = false;

function onScroll(){
  latestScrollY = window.scrollY || window.pageYOffset;
  if (!ticking){
    window.requestAnimationFrame(() => {
      const offset = Math.min(40, latestScrollY * 0.12);
      if (heroImg){
        heroImg.style.transform = `translateY(${offset}px) scale(1.08)`;
      }
      ticking = false;
    });
    ticking = true;
  }
}
```

**Объяснение:**

- `window.scrollY` - текущая позиция прокрутки
- `requestAnimationFrame` - оптимизированная анимация
- `ticking` - флаг для предотвращения множественных вызовов
- `transform` - CSS трансформация для параллакса

### 6. 3D эффект наклона карточек

```javascript
function bindTilt(el){
  const strength = 10;
  let rect;
  
  function onMove(e){
    rect ||= el.getBoundingClientRect();
    const cx = rect.left + rect.width/2;
    const cy = rect.top + rect.height/2;
    const dx = (e.clientX - cx) / (rect.width/2);
    const dy = (e.clientY - cy) / (rect.height/2);
    const rx = (+dy * strength).toFixed(2);
    const ry = (-dx * strength).toFixed(2);
    el.style.transform = `rotateX(${rx}deg) rotateY(${ry}deg)`;
  }
  
  el.addEventListener('mousemove', onMove);
  el.addEventListener('mouseleave', () => {
    el.style.transform = '';
    rect = undefined;
  });
}
```

**Объяснение:**

- `getBoundingClientRect()` - получение позиции элемента
- `clientX/clientY` - координаты мыши
- `rotateX/rotateY` - 3D поворот по осям
- `mousemove` - событие движения мыши
- `mouseleave` - событие выхода мыши
